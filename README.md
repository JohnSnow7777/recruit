# 마이파크 스크린파크골프 비즈니스 딜러 모집 랜딩페이지

- 배포 라이브 URL: https://recruit-pi-one.vercel.app/
- 공식 깃허브 저장소: https://github.com/JohnSnow7777/recruit
- 공식 본사: 주식회사 스마일스퀘어 (마이파크 스크린파크골프 본사)

## 구글 스프레드시트 없이 이메일(maxmook@naver.com)만 바로 받는 설정 방법 (3분 완료)

구글 스프레드시트를 만들지 않고도, 독립형 구글 앱스 스크립트를 통해 폼 입력 즉시 `maxmook@naver.com`으로 신청 알림 이메일을 전송할 수 있습니다.

### 1단계: 독립형 구글 앱스 스크립트 열기
1. 인터넷 브라우저 주소창에 `script.new`를 입력하고 접속합니다. (구글 로그인 상태)

### 2단계: 코드 붙여넣기 및 저장
1. 화면에 보이는 기존 `function myFunction() {}` 코드를 모두 지웁니다.
2. `google_apps_script.js` 파일의 전체 코드를 복사하여 붙여넣고 저장(Ctrl + S)합니다.

### 3단계: 웹앱으로 배포하기
1. 우측 상단 **[배포] → [새 배포]**를 클릭합니다.
2. 좌측 톱니바퀴 아이콘을 누르고 **[웹 앱]**을 선택합니다.
3. 설정값을 다음과 같이 지정합니다:
   - **설명**: 마이파크 딜러 신청 이메일 전송
   - **다음 사용자로 실행**: **나(내 계정)**
   - **액세스 권한이 있는 사용자**: **모든 사용자(Anyone)**
4. **[배포]** 버튼을 클릭하고 구글 권한 요청 시 승인합니다.
5. 발급된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.

### 4단계: 랜딩페이지에 URL 적용
1. 복사하신 웹 앱 URL을 채팅창에 알려주시면, 즉시 상세페이지 `index.html`에 연결하여 라이브에 배포해 드립니다.
2. 추후 구글 스프레드시트가 필요해지면 시트의 [확장 프로그램] → [Apps Script]로 연결하여 똑같이 사용하실 수 있습니다.
